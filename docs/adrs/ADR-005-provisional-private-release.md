# ADR-005: Private Evaluation Until IP Decision

- Status: Accepted provisionally
- Date: 2026-08-21

## Context

The source plan identifies possible patent claims but explicitly states that novelty and patentability
are unconfirmed. Premature public disclosure may affect options in some jurisdictions.

## Decision

Mark the repository as private evaluation code with all rights reserved. Do not choose an open-source
license or publish until the prior-art matrix and qualified IP review are complete.

## Consequences

Collaboration must remain controlled. This is a project-management decision, not a legal conclusion.
The ADR must be revisited before any public repository, package upload, talk, paper, or benchmark
release that discloses implementation detail.
